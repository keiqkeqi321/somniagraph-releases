# SomniaGraph desktop downloads

This public repository distributes Windows x64, Mac Intel x64, and Mac Apple Silicon arm64 installers. The application source repository is private.

- Product website and download guide: https://graph.somnia.top/#downloads
- All published builds: https://github.com/keiqkeqi321/somniagraph-releases/releases

Each release includes a complete three-platform installer set, both Mac update ZIPs, SHA256SUMS, and release-manifest.json with sizes, SHA-256/SHA-512, and the source commit. Downloads are served directly by GitHub.

Preview tags (vX.Y.Z-preview.N, -beta.N, or -rc.N) are not publisher-signed or notarized; automatic updates are disabled for preview builds. Stable tags (vX.Y.Z) require platform signing and Mac notarization in CI.

Release files are immutable. Use a new version tag for new contents.
